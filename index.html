Problem

Raw numerical and categorical datasets often contain missing entries, skewed feature distributions, and outliers that prevent standard linear regression algorithms from generalizing accurately to unseen test instances.

Solution

Engineered a modular Python pipeline that automates data imputation, performs feature scaling (StandardScaler), trains multiple baseline models (Ridge, Random Forest Regressor), and outputs cross-validated comparative performance metrics.

Key Features
  • Automated missing value imputation & one-hot encoding for categorical variables
  • Correlation matrix heatmaps and feature importance ranking visualization
  • Multi-metric validation logging (MAE, RMSE, and R² Score) across 5-fold splits
  • Clean, reproducible Jupyter Notebook workflow with documented mathematical steps
View on GitHub Academic / Student Build
Problem

Students and researchers frequently need to extract key answers and summaries from dense PDF lecture notes and technical textbooks without manually skimming hundreds of pages or suffering LLM hallucination.

Solution

Built a prototype Retrieval-Augmented Generation (RAG) exploratory system that chunks documents, generates semantic embeddings, queries a local vector index, and constructs grounded prompts to provide source-attributed answers.

Key Features
  • Document text chunking with configurable overlap to preserve technical context
  • Cosine similarity retrieval over local vector database chunks
  • Prompt template design enforcing "answer only from provided context" to mitigate hallucinations
  • Lightweight interactive Streamlit web dashboard for uploading notes and querying in real time
